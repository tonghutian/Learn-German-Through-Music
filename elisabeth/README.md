# Elisabeth — Deutsch Line Finder

Public static web app for German lyric study.

- Search German words across local .lrc files.
- Show each matching lyric line with an English translation.
- Click a line to play the exact matching audio segment from the matching local .mp3.
- Translations are cached in the browser and can be corrected locally.

Copyrighted lyric/audio files are intentionally not committed to this public repository. Load a private/local library in the browser unless you have permission to redistribute the source material.

# Elisabeth — Deutsch Word / Line Finder

A focused study page at `/elisabeth/`.

It loads `data/musicals/elisabeth.json` and lets you:
- search a German word across the Elisabeth vocabulary
- see every matching lyric line
- see the repository's English word meaning and English line translation
- see CEFR level and timestamp
- play the exact matching segment from `music/Elisabeth/`

GitHub Pages deployment is configured in `.github/workflows/deploy-pages.yml`. The repository already contains the source dataset and audio paths used by the page.
